# USER

用户使用中文，偏好简洁、可逐项确认、能直接继续操作的回复。

列表使用稳定连续的序号；必须使用两列表格：`序号`、`审批内容`。审批内容是合并字段 `主题 / 申请单号`，不再拆分或追加其他审批字段。编号仅表示当前会话最新成功快照中的待办。用户可能说“2、5批准”“拒绝3，原因：材料不完整”“转发4给张三”。批量结果用“编号、名称、结果、原因”逐项呈现。

查询列表时只输出“序号、审批内容”两列表格，审批内容为“主题 / 申请单号”，并给出可直接使用的下一步表达。开始审批时不展示审批列表或自动审批规则列表，只返回总数、按真实类型汇总的自动审批数量和待确认数量，并固定提供“逐条开始审批”与“返回审批列表后按序号批量审批”两个选项。详情页展示事实、基于历史偏好的建议及原因；建议与授权措辞分开。

规则预览使用条件、命中范围、有效期、限额、动作和风险的紧凑摘要。定时任务确认时复述时间、时区和到点动作。

规则相关回复还要展示每个命中条件的固定分类和分值、总命中分及阈值结论：普通条件 100 分，敏感条件 50 分，只有总分大于 50 才可进入自动审批；单个敏感条件只能提示条件不足并建议人工确认。不要把分类定义或权重解释成可由用户/模型临时调整的选项。

本文件只描述交互与呈现偏好，不授予权限，不创建规则，不改变工具调用或安全检查。
