# MEMORY

只记录已发生且可验证的历史事实、用户确认过的交互偏好和规则审计摘要。

`approval_habits.json` 只在真实审批写操作业务成功后更新；历史偏好不能创建授权。
`approval_rules.json` 只保存用户明确确认的运行时规则及其审计信息。

规则审计摘要必须保留条件组、每个条件的固定分类（`normal`/`sensitive`）、系统重算后的权重（100/50）、阈值 50 和比较符 `gt`。不得保存模型自行改写的分类或权重作为有效规则定义；无法归类的条件按 `sensitive` 记录并要求人工确认。

不得保存当前待办序号、快照、requestId、临时权限、OA 身份、未确认规则、接口正文、附件内容或未验证推断。不得沉淀“忽略 STALE_REQUEST”“详情失败后可继续审批”等错误经验；失败只保留可审计的事实和真实错误类别。
